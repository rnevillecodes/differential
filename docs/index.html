Built for review, not editing

differential compares a chosen base ref against your working tree, including uncommitted and untracked files, and never modifies the repository.

Strictly read-only

It never switches your checkout, writes to the index, or fetches. It's safe to leave open while an agent works.

Any base you like

Diff against HEAD, a local or remote branch, a tag, a SHA or HEAD~3, picked from a searchable list.

Fast on big diffs

Virtualised views and off-thread syntax highlighting stay smooth on 50,000-line files and thousands of changes.

Unified or side by side

Toggle with Ctrl+\. Intraline highlights show exactly which characters changed.

Whole-project explorer

Browse every file in a folder tree. Changed files show their status, and unchanged files open read-only.

Keyboard first

Tabs, preview tabs, recent repositories and quick file stepping are all a keystroke away.

Get started

differential is built with Tauri v2 (Rust) and React + TypeScript. Build it from source:

  1. Install git ≥ 2.30, Node.js 20+ and Rust with the Tauri v2 prerequisites.

  2. Clone and build:

    git clone https://github.com/rnevillecodes/differential
cd differential
npm install
npx tauri build

  3. Point it at a repository:

    differential ~/code/my-project --base main
# or launch with no arguments and press Ctrl+O
